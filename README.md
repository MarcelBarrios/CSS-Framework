# Nexus CSS Framework

Nexus is a lightweight, drop-in CSS framework designed for marketing pages, documentation, and internal tools. It provides semantic HTML styling out of the box (classless base) and a robust set of components powered by modern CSS features.

## How to Use

1. Download `acsd.css` and place it in your project folder.
2. Link it in your HTML `<head>`:

```html
<link rel="stylesheet" href="acsd.css">
